# Публикация зондирования по расписанию

Утром в 11:00 и вечером в 23:00 по Якутску в группу приходит свежая
диаграмма Skew-T со сводкой. Зимой к ней добавляется блок зимних явлений.

## Установка

**1. Файлы в репозиторий.** В корень:

    daily_post.py
    sharppy_core.py
    winter_hazards.py
    environment.yml

и расписание:

    .github/workflows/daily.yml

**2. Ключи в Secrets.** Settings → Secrets and variables → Actions →
New repository secret:

| Имя | Что вписать |
|---|---|
| `TELEGRAM_TOKEN` | токен бота от BotFather |
| `TELEGRAM_CHAT` | номер группы, например `-1003283192014` |

**Токен нельзя класть в код.** Сейчас он вписан прямо в
`SHARPpy_tgBOT3.py` — этот файл в публичный репозиторий загружать
нельзя, иначе токеном сможет пользоваться кто угодно.

**3. Проверка.** Actions → «Зондирование в группу» → Run workflow.
Можно указать свою команду в поле ввода.

## Как выключить

Создайте в корне репозитория файл с именем `PAUSED` — расписание будет
просыпаться, видеть его и ничего не публиковать. Внутрь можно написать
причину, она попадёт в лог.

Через веб-интерфейс GitHub: Add file → Create new file → имя `PAUSED`
→ Commit. С телефона так же через приложение GitHub.

Чтобы возобновить — удалите файл.

**Почему не команда из Телеграма.** У расписания нет постоянно
работающего процесса: Actions просыпается по времени, делает дело и
засыпает. Слушать сообщения некому. Команда из группы возможна только
у бота, который крутится на вашем компьютере.

## Расписание

Задаётся в UTC, а Якутск живёт по UTC+9:

| cron | местное время | что публикуется |
|---|---|---|
| `0 2 * * *` | 11:00 | зонд 00 UTC (выпущен в 9 утра) |
| `0 14 * * *` | 23:00 | зонд 12 UTC (выпущен в 21:00) |

Менять — в `.github/workflows/daily.yml`.

## Чего здесь пока нет

**Карт.** `gfs_maps.py` — это окно tkinter, на сервере его не запустить.
Нужна отдельная безоконная версия: та же логика расчёта, но без
интерфейса, с настройками из файла. Работа сделаема, но не мелкая.

**Проверьте расход минут.** Для публичных репозиториев Actions
бесплатны без ограничений, для приватных есть месячный лимит. Сборка
окружения кэшируется, так что после первого запуска будет быстрее.

## Если не сработает

Смотрите в Actions последний запуск. Частые причины:

- **не установилось окружение** — SHARPpy тянет много зависимостей,
  бывает конфликт версий; посмотрите шаг «Поставить окружение»;
- **нет данных** — сервер зондирований бывает недоступен, тогда в
  группу придёт сообщение об этом, а не тишина;
- **не отправилось** — проверьте, что бот добавлен в группу и имеет
  право писать.
